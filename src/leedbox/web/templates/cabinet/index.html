Как читать показатели

Запуск — человек открыл ссылку подарка и запустил бот. Люди — уникальные Telegram ID, повторы не увеличивают число людей. Выдача — подтверждённая отправка подарка; повторная отправка считается отдельно.

Источник определяется по метке ссылки, а не автоматически: пересланная ссылка сохранит исходную метку. Без метки статья или видео неизвестны. Просмотры публикаций не учитываются. Выдачи по конкретному источнику не приписываются: текущие данные не связывают их с публикацией. Уникальных людей разных строк нельзя складывать.
